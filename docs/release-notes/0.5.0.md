# MCP server

Moonrow can now serve its connections to MCP clients such as Claude Code and Codex. A client sees your saved connections, opens one in Moonrow and runs queries there, so every statement shows in the workspace’s query log and history.

Each client uses an access token that is Read Only, Read & Write or Full Access, for every connection or only the ones you choose. A statement that may change data waits for you to click Allow in its workspace, and then goes through the connection’s safe mode. Window ▸ MCP Activity shows what each client did.

Turn the server on in Settings ▸ MCP, which also shows how to set up each client. It listens on this Mac only, unless you allow connections from other computers, over TLS.

## Bundled backup tools

Backup and Restore now use client tools that come with Moonrow, so there’s nothing to install first: pg_dump, pg_restore and psql for PostgreSQL 10 to 18, and the tools for MySQL 5.7, MySQL 8.0 and MariaDB. When you connect, the window picks the version that suits the server, and you can choose another from its menu.
