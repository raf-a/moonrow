# Sidebar redesign

The History pane now shows each statement coloured and laid out as you wrote it, so you can spot a past query at a glance. Collapse a day’s heading to fold it away.

Long table names now stay on one line, shortened in the middle, so names that start the same way are easy to tell apart.
