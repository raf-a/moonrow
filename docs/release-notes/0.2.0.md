# Query folders

Saved queries are now plain `.sql` files, kept in a folder for each connection. Moonrow watches the folder and keeps the Queries pane in step with it. Edit a query in another editor or drop a file in from Finder, and the change shows up straight away.

A connection’s folder is named after the connection, but it can be any folder on your Mac. Connections that use the same folder share their queries. When you change a connection’s folder, Moonrow offers to move the queries that are already there.

Save and Save As… (⇧⌘S) now use the standard save panel, which opens in the queries folder. Click a query in the Queries pane to preview it in a tab; once you start typing, the tab stays. Saved queries save themselves as you type.

## Unsaved query indicators

A query tab holding text that isn’t saved anywhere now shows a dot in place of its close button, and so does the window’s close button. Closing a window with several unsaved queries asks once, and Review Changes… takes you through them one at a time.

Quitting saves anything typed in saved queries in the last second. If a workspace can’t reconnect at launch, its tabs come back the next time you open that connection.

## Error locations

A script that failed used to stop without saying where. Now the token the server pointed to is underlined in the editor and scrolled into view.

Postgres errors also keep their detail and hint, and the summary shows how far the script got. For example: “3 of 5 statements ran · statement 3 failed”.

## Run button

The query toolbar now has one Run button. It runs the selection when there is one. Otherwise it runs the current statement or the whole script, whichever you pick in its menu. While a query runs, Stop takes its place, so nothing else in the toolbar moves.

Beautify SQL and Compact SQL are in the same menu.
