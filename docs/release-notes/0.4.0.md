# Open Database

Open Database (⌘K) now switches the workspace to another database on the server, so you can move between databases without a second connection. On Postgres the workspace reconnects to the database you choose: query tabs stay open, and the workspace comes back in that database at the next launch. MySQL and MariaDB switch databases here too, in place of the sidebar’s switcher.

Click New… to create a database with an encoding and collation from the server’s own lists. The list’s menu also has Open in New Tab, Copy Name, Rename… (Postgres) and Drop….

## Encrypted and remote SQLite

SQLite connections now open databases encrypted with SQLCipher. Save the passphrase in the connection’s Passphrase field, or have Moonrow ask for it each time.

A SQLite connection can also go through SSH. The file stays on the server and statements run there with the server’s own sqlite3, so your changes go straight into the live file. If the server has no sqlite3, Open a Copy opens a copy of the file instead, and changes to it stay on your Mac.

## Touch ID in safe mode

Safe mode’s password levels can now take Touch ID instead of the password. Turn on “Use Touch ID instead of the password” in Settings ▸ General. If Touch ID doesn’t recognise you, the password field is still there.

## Fixes

- [Connections] Fixed a workspace reopened at launch sometimes staying in the default schema instead of the one it was in

## Improvements

- [Connections] Added bootstrap commands: SQL that a connection runs after every connect and reconnect, set in the connection form
- [Connections] An open connection can now be edited; its name, tag and safe mode change at once, and the rest at the next connect
- [Connections] Test and Connect now say when a MySQL connection reached a MariaDB server, or the other way round, and offer to change the type
- [Postgres] Added direct TLS negotiation, for PostgreSQL 17 and later
- [MySQL] Added an SNI server name for TLS connections to MySQL and MariaDB
- [Settings] Added a query timeout: a statement run from a query tab now stops after 300 seconds, unless you change the limit in Settings ▸ General
